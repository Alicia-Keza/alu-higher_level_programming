# ALU - Higher Level Programming

This folder contains the Higher Level Programming projects and exercises completed for ALX/African Leadership University (ALU) tracks. The exercises are grouped by topic and include Python programs, object-oriented exercises, and SQL query practice files.

**Repository Overview**
- **Purpose:** Collection of practice exercises that demonstrate Python fundamentals, OOP, data structures, error handling, file I/O, networking basics, and SQL queries.
- **Audience:** Students and reviewers following the ALU/ALX curriculum.

**Structure**
- **Top-level folders:** Each folder groups related exercises. Examples include `python-hello_world`, `python-if_else_loops_functions`, `python-data_structures`, `python-classes`, `python-more_classes`, `python-network_0`, `python-network_1`, `python-test_driven_development`, and `SQL_introduction`.
- **SQL files:** The `SQL_introduction` and top-level SQL files contain standalone `.sql` queries and schema examples.

**Requirements**
- **Python:** 3.8+ (use `python --version` to verify)
- **SQLite3 / SQL client:** To run `.sql` files you can use `sqlite3`, `mysql`, or your preferred SQL engine depending on the exercise.

**How to run Python exercises**
- Run a single script from this folder (or any subfolder) with:

```
python path/to/script.py
```

- If a script uses external libraries, install them with `pip` first. (There is no global `requirements.txt` in this folder.)

**How to run SQL examples**
- Using SQLite3 (example):

```
sqlite3 :memory: < 0-list_databases.sql
```

- Or open your preferred SQL client and execute the `.sql` files directly.
